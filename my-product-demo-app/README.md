# my-product-demo

My Product is a leaf vacuum that has the ability to pick up small leaves without picking up dirt or mulch, which avoids ruining soil beds.

This repository contains a small classroom demo web app (React + Vite) for the product. It includes a short product page and one workflow: a visitor reads about the product and submits feedback.

## Run locally

```
npm install
npm run dev
```

## Build

```
npm run build
```

The production files are written to `dist`. When deployed on Vercel, use the Vite preset with build command `npm run build` and output directory `dist`.
